# Mars Command

Mars Command is a Minecraft community and desktop launcher. The launcher helps
set up and update the files needed to play on the Mars server.

## Start here

1. Visit the [Mars Command website](https://mars.nexusgit.info/) for server
   information and a simple getting-started guide.
2. Open the [launcher releases page](https://github.com/Mars-Command/Client-Launcher/releases)
   and download the latest installer for your computer.
3. Open the installer, then follow the steps shown by the launcher.

The launcher is currently for **Windows and Linux**. On the releases page,
choose the installer for your computer, not the “Source code” files.

## What the launcher does

- Sets up the Mars Minecraft files in their own place.
- Checks and updates those files for you.
- Helps you open Minecraft and connect to the Mars server.

You do not need to use a command line or type commands to get started.
